SAUR

Security Analysis & Threat Engine

A fast system auditor that scans files and memory for bad actors, credential leaks, and malicious payloads using AVX2 vector instructions, YARA rulesets, and live URLhaus indicator feeds. Features hardware-accelerated signature scanning, Google RE2 pattern matching, and deep recursive filesystem analysis.

Threat-Matrix

Serverless Edge-Native Threat Intelligence Dashboard

A serverless, edge-native dashboard that aggregates live CVEs, exploits, and security news into a single stream. Built entirely on Cloudflare Workers and D1 for sub-millisecond latency without traditional backend bloat. It features a zero-trust, completely anonymous authentication model requiring a strict 128-character cryptographic passphrase, guaranteeing full user privacy with zero ad tracking.

dSBOM

Dynamic runtime SBOM generator for Linux

Non-invasive runtime Software Bill of Materials (SBOM) generation engine. The system derives component identity, linkage, and cryptographic integrity assertions natively from the Linux kernel virtual filesystem (VFS) and tracer subsystems, eliminating userspace injection, application instrumentation, or static manifest approximation.

ZeroShadow

Lightweight ELF Tracing & Instrumentation Engine

ZeroShadow is a lightweight C++ engine for tracing and instrumenting ELF binaries. It gives you raw, low-level visibility into how a program runs, allowing you to hook functions, trace execution paths, and analyze binaries without the bloat of heavy runtimes. Built for both CLI analysis and direct integration into your own tools as a library.

Project KASCVE

Automated Security Auditing Ecosystem & Penetration Tester

KASCVE is an automated security audit software for websites that tests your website for known CVE'S and Top 10 OWASP vulnerability with an addition of active penetration test such as SQL Injection and some others. A platform made for both desktop and android.

AUR-scanner

Offline Static Analysis Utility

A lightweight offline static analysis tool to scan local ALPM metadata and AUR helper build caches for heuristic anomalies and known threat signatures.
